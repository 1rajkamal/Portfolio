# 🌐 3D Interactive Developer Portfolio

An interactive, 3D WebGL developer portfolio built with **React 18**, **Three.js**, **React Three Fiber (@react-three/fiber)**, **Drei**, **Tailwind CSS**, and **TypeScript**, hosted on GitHub Pages.

## 📌 Overview

A modern personal showcase delivering an immersive 3D spatial experience. Rather than a static document, this portfolio presents technical projects, core skills, certifications, and engineering experience through a responsive WebGL canvas paired with modern UI overlays.

---

## 🚀 Key Features

- **3D Spatial Environment:** Real-time rendering of 3D floating islands, atmospheric lighting, and time-trial tracks using Three.js and `@react-three/drei`.
- **Interactive HUD & Terminal:** Holographic HUD overlays, Matrix rain animations, and simulated command terminal modals.
- **Projects & Skills Showcase:** Categorized technical projects, verifiable certification links, and hackathon highlights.
- **Dynamic Scroll Animations:** Context-driven color backdrop transitions matching page scroll position.
- **Performance Optimized:** Lazy loading, asset bundling via Vite, and responsive mobile fallbacks.

---

## 🛠️ Tech Stack

- **3D Graphics & Physics:** Three.js, `@react-three/fiber`, `@react-three/drei`, `@react-three/rapier`
- **Framework & UI:** React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Build Tool:** Vite
- **Deployment:** GitHub Pages (`gh-pages`)

## ⚡ Local Setup & Development

```bash
# 1. Clone repository
git clone https://github.com/1rajkamal/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```
Open **http://localhost:5173** to view the portfolio.
